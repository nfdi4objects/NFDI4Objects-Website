## Description

This TRAIL is intended to support community-driven further development and proof of concept for the NFDI4Objects Object Ontology (N4O OO), which is based on the ISO 21127 standard (CIDOC CRM 7.1.3), as well as the further development of multidisciplinary use cases in the WissKI virtual research environment for the creation of object biographies. To this end, meaningful objects are selected that are well-documented and have a complex history, which can be used to develop the data model.

The use cases that have already been created and those currently in progress are freely accessible online at: [https://nfdi4objects.wisski.data.fau.de/use_cases](https://nfdi4objects.wisski.data.fau.de/use_cases)
(External link).

Plans include the creation of object biographies for digital reconstructions of objects, as well as for the “Excavation” use case and for scientific data. Documentation of the data model will be further advanced, and there are plans to implement the consortium’s core object dataset—currently under development and coordination—in WissKI based on the N4O Object Ontology.

The data model for object biographies offers a wide range of scientific and strategic advantages: contextuality, interoperability, information provenance, sustainability, extensibility, and participation.

The data model and application ontology are published on GitHub and can potentially be reused in other research contexts and systems: [https://github.com/nfdi4objects/n4o-ontology](https://github.com/nfdi4objects/n4o-ontology)
