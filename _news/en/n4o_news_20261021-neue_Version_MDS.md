The Minimum Data Set Recommendation for Museums and Collections, Version 1.2, has been published:

Wiki: [German](https://deutsche-digitale-bibliothek.atlassian.net/wiki/spaces/DFD/pages/48104499/Minimaldatensatz-Empfehlung+f+r+Museen+und+Sammlungen+MDS+v1.2), [English](https://deutsche-digitale-bibliothek.atlassian.net/wiki/spaces/DFD/pages/48103806/English+Version+Minimum+Record+Recommendation+for+Museums+and+Collections+v1.2)

Zenodo (PDF): German, [https://zenodo.org/records/23059485](https://zenodo.org/records/23059485) English [https://zenodo.org/records/23059685](https://zenodo.org/records/23059685)

### The following new features have been added:

- Minor adjustments to the [home page](https://deutsche-digitale-bibliothek.atlassian.net/wiki/spaces/DFD/pages/48104499/Minimaldatensatz-Empfehlung+f+r+Museen+und+Sammlungen+MDS+v1.2) of the guidelines: names and logos of the participating institutions have been added
- Additions to the data entry guidelines on the data field pages:
- [Object title or designation](https://deutsche-digitale-bibliothek.atlassian.net/wiki/spaces/DFD/pages/48103813/Objekttitel+oder+-benennung+Pflicht): Additional guidance on recording
  natural history objects
- [Classification:](https://deutsche-digitale-bibliothek.atlassian.net/wiki/spaces/DFD/pages/48104542/Klassifikation+Recommended) Additional guidance on inventorying
- [Material:](https://deutsche-digitale-bibliothek.atlassian.net/wiki/spaces/DFD/pages/48104549/Material+Recommended) Additional guidance on inventorying
- [Technique:](https://deutsche-digitale-bibliothek.atlassian.net/wiki/spaces/DFD/pages/48104540/Technik+Recommended): Additional guidance on inventorying
- [Dimensions:](https://deutsche-digitale-bibliothek.atlassian.net/wiki/spaces/DFD/pages/48104664/Ma+e+Recommended) Additional information on inventorying
- [Event type:](https://deutsche-digitale-bibliothek.atlassian.net/wiki/spaces/DFD/pages/48104059/Ereignistyp+P) Additional notes on the recording of natural history objects
- [Person/Organisation:](https://deutsche-digitale-bibliothek.atlassian.net/wiki/spaces/DFD/pages/48103965/Person+K+rperschaft+Conditionally+mandatory) Additional notes on the recording of natural history
  objects
- [Date:](https://deutsche-digitale-bibliothek.atlassian.net/wiki/spaces/DFD/pages/48104553/Datierung+Conditionally+mandatory) Additional notes on recording natural history objects
- [Holding institution:](https://deutsche-digitale-bibliothek.atlassian.net/wiki/spaces/DFD/pages/48104568/Verwahrende+Einrichtung+Pflicht) Additional notes on inventorying
- [Date of the data record:](https://deutsche-digitale-bibliothek.atlassian.net/wiki/spaces/DFD/pages/48104571/Datierung+des+Datensatzes+Empfohlen): Additional notes on inventorying
- The following standards have been included in the concordance tables on the data field pages:
  - [Darwin Core](https://dwc.tdwg.org/)
  - [Linked.Art](https://linked.art/)
  - [Schema.org (v30.0, CreativeWork)](https://schema.org/Thing)
- A concordance table has been created on the [Alternative text](https://deutsche-digitale-bibliothek.atlassian.net/wiki/spaces/DFD/pages/48104061/Alternativtext+Recommended) data field page.
- [The cross-reference to the CCC data field catalogue](https://deutsche-digitale-bibliothek.atlassian.net/wiki/spaces/DFD/pages/264077319/CCC-Datenfeldkatalog) has been updated with links, as it has now
  been published.


Strictly speaking, the following changes are not part of v1.2, as the
pages outside the data field catalogue have been decoupled from the versioning. However, these
were only added after the release of v1.1.

- The [FAQ](https://deutsche-digitale-bibliothek.atlassian.net/wiki/spaces/DFD/pages/48104006/FAQs)
  page has been updated and expanded: amongst other things, new FAQs regarding collection management, rights to cultural heritage objects and vocabulary recommendations have been added or updated.
- The [Resources and Links](https://deutsche-digitale-bibliothek.atlassian.net/wiki/spaces/DFD/pages/48103934/Ressourcen+und+Links) section has been restructured. It now consists of
  several subpages and the content has been expanded. Some of the changes in this section:
  - The list of [software providers](https://deutsche-digitale-bibliothek.atlassian.net/wiki/spaces/DFD/pages/895451143/Softwareanbieter+innen+und+Verb+nde) has been updated: it now includes
  a detailed overview of the features of the software products in
  relation to the minimum data set recommendation. The overview will
  be expanded gradually as software providers inform the
  working group of any new developments.
- The [Success Stories](https://deutsche-digitale-bibliothek.atlassian.net/wiki/spaces/DFD/pages/389218305/Success+Storys) page has been updated. It features short interviews with
  various users of the minimum data set recommendation for museums and
  collections
- The [Credits and Citation Guide](https://deutsche-digitale-bibliothek.atlassian.net/wiki/spaces/DFD/pages/48103973/Credits+und+Zitationshinweis) page has been updated.
- The [Acknowledgements](https://deutsche-digitale-bibliothek.atlassian.net/wiki/spaces/DFD/pages/48104372/Dank) page has been updated.

### Consultation Hours

Are you interested in the minimum data set recommendation for museums and collections,
but aren’t quite sure how best to incorporate it into your documentation work?
Do you have questions about individual data fields, the data entry guidelines or the recommended vocabularies? The consultation session is aimed at museum staff, software providers, digital researchers and anyone who uses the recommendation in their work and has any unanswered questions.
Do come along!

The next consultation session will take place on 25 November 2026 from 2 pm to 3 pm.
We would appreciate it if you could register using the following form (please select ‘LIDO Service Centre’ from the drop-down menu): [nfdi4culture.de/de/helpdesk.html](https://nfdi4culture.de/de/helpdesk.html)
