In this hands-on introductory workshop—a collaboration between NFDI4Objects and the Data Competence Center [HERMES](https://hermes-hub.de/)—participants will learn about Markdown as a versatile markup language and how to use it quickly to create PDFs, websites, and more. Step by step, an efficient workflow is taught—from creation and flexible output formats to reusable templates for FAIR OER. Ideal for anyone who wants to write and publish (academic) texts in a straightforward and sustainable way.

In the hands-on first part, participants learn about Quarto’s core functionalities: the structure of Quarto documents, working with Markdown and YAML headers, and embedding visualizations—such as illustrations or code—directly into the text. They also learn how to precisely control layout and output and how to generate different publication formats—such as PDFs or websites—from a single document.  
In the second part, the focus is on the reusability of academic content. Participants will learn about templates, customize them, and receive an introduction to FAIRe Open Educational Resources (OER) using templates from the NFDI4Objects context to design materials that are sustainable and reusable.

**Conditions of participation:**
Before the event, participants will be sent installation instructions, which should be followed independently in advance.  
If you have any questions or encounter any problems, we are offering **a setup session on 7 July from 11am to 12pm**.  
The course is aimed at beginners; therefore, no prior knowledge of programming or markup languages is required. Please note that you will need a computer with internet access to complete the exercises.
