### Description:
How can vocabularies, authority data and metadata standards for buildings be better linked and made usable for the community’s needs? At this follow-up meeting, we will discuss the requirements for the description and indexing of buildings together with representatives from various institutions and specialist communities.

### Key topics:

- User perspective
- Building standard data and minimum data sets
- Interoperability
- Opportunities for process automation

In addition to expert input and discussion, there will be time set aside for a collaborative working session.
