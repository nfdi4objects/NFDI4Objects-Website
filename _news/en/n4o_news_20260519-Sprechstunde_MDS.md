Are you interested in the [Minimum Data Set Recommendation for Museums and Collections](http://www.minimaldatensatz.de/) but not sure how best to incorporate it into your documentation work? Do you have questions about specific data fields, the data entry guidelines, or the recommended vocabularies?

The Minimum Data Set Working Group, in collaboration with the LIDO Service Center (NFDI4Culture), offers regular consultation hours.  
These consultation hours are aimed at museum staff, software providers, digital researchers, and anyone else who would like to use the recommendation in their work and has questions.

The consultation hours will take place on the following dates this year: **May 20, July 8, September 23, and November 25, 2026, from 2:00 PM to 3:00 PM each day.**

Registration is requested via the following [form](https://nfdi4culture.de/de/helpdesk.html) (please select “LIDO Service Center” from the dropdown menu).

[To the NFDI4Culture Consortium](https://nfdi4culture.de/index.html)  
[To the Minimum Data Set Working Group](https://www.museumsbund.de/ag-minimaldatensatz/)
